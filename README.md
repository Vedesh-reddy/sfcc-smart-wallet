# sfcc-smart-wallet

SFCC/SFRA cartridges for a stored-value wallet in USD (sandbox, not for live money): sandbox top-ups, wallet-only and split payments with holds and e-mail step-up codes, family members with limits, refunds to the wallet and a Business Manager wallet desk on a balanced double-entry ledger - with tests and illustrated docs.

The cartridges arrive through the phase pull requests.
